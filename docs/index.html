초파리 한글 실험

수컷 초파리 커넥톰(MaleCNS v1.0)의 후각–버섯체 회로에 한글 자모를 넣고, 출력 뉴런 활동만으로 자모와 글자 조합 규칙을 구분할 수 있는지 검증합니다. 회로 연결은 고정되어 있고, 학습하는 것은 회로 바깥에 붙인 선형 분류기입니다.

① 회로 지도

원 크기 = 뉴런 수 · 선 굵기 = 시냅스 수 · 원이나 선에 마우스를 올리면 수치가 보입니다

주 경로 (입력 → 출력)그 밖의 연결 (되먹임·국소 연결)

표 보기: 보내는 쪽 → 받는 쪽 시냅스 수

행 = 보내는 뉴런, 열 = 받는 뉴런. 색이 진할수록 시냅스가 많습니다(로그 척도).

② 자모 → 출력 반응

행 = 자모 40개, 열 = MBON 97개. 각 열 안에서 가장 약한 반응 = 연한 색, 가장 강한 반응 = 진한 색 (노이즈 σ=0.5, 실제 커넥톰, 평균). 칸에 마우스를 올리면 값이 보입니다.

③ 성적표 — 단계 A: 자모 40개 알아보기

가로 = 입력 노이즈 세기(σ), 세로 = 처음 보는 샘플의 정답률. 점 = seed 5개 평균, 세로 막대 = 최솟값~최댓값. 점선 = 찍기(2.5%).
